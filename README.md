# ЖК Construction Chat

A beautiful, professional chat application designed specifically for construction team communication. This modern interface reflects the strength and precision of construction work while providing a functional and visually appealing communication platform.

## Features

- Real-time messaging
- User avatars with initials
- Message history display
- Responsive design
- Construction-themed UI with professional styling
- Smooth animations and transitions
- Online user status indicators

## Technologies Used

- React.js
- Vite (build tool)
- React Icons
- CSS3 with modern styling techniques
- JavaScript ES6+

## Installation

1. Clone the repository:
```bash
git clone <your-repository-url>
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at http://localhost:5173

## Usage

The chat interface is designed for construction teams to communicate efficiently about projects, schedules, deliveries, and safety updates. The clean, professional design ensures important information is communicated clearly and effectively.

## Design Philosophy

The interface uses a construction-themed color palette with blues and accent colors that reflect the strength and reliability of construction work. The subtle grid background pattern evokes construction blueprints and technical drawings, while maintaining a clean, professional appearance.

## Deployment

This application can be deployed to GitHub Pages, Vercel, Netlify, or any static hosting service.
